Projeto integrador de modelagem de dados para uma pequena empresa familiar de semijoias. Parti da análise de processos e requisitos para construir o modelo conceitual (DER) de um sistema ERP.

**Pratiquei:** modelagem de dados, DER, análise de requisitos.

### [Criptografia em duas camadas](https://github.com/Gramacho05/criptografia-duas-camadas)
Programa em C que criptografa uma palavra em duas camadas: cifra de César e deslocamento por uma sequência numérica (PA, PG, Fibonacci ou primos). Tem menu, descriptografia, comparação entre as sequências e grava o resultado e um log de execução em arquivo.

**Pratiquei:** linguagem C, progressões e séries, manipulação de arquivos, lógica de programação.
